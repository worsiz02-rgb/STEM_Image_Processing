# STEM Image Processing

## Обробка зображень текстових документів

Навчальний STEM-проєкт із дисципліни «Комп'ютерна графіка та обробка зображень».

Проєкт присвячений дослідженню алгоритмів цифрової обробки зображень текстових документів.

Програму реалізовано мовою Python із використанням графічного інтерфейсу Tkinter.

## Мета проєкту

Метою проєкту є розробка програмного застосунку для обробки зображень текстових документів, реалізація алгоритмів цифрової обробки та експериментальне порівняння їхніх результатів.

Основні завдання:

1. Реалізувати п'ять алгоритмів обробки зображень.
2. Розробити графічний інтерфейс користувача.
3. Забезпечити завантаження та збереження зображень.
4. Реалізувати обчислення метрик MSE, PSNR і Global SSIM.
5. Провести експерименти на наборі тестових документів.
6. Порівняти алгоритми за числовими показниками та часом виконання.
7. Побудувати графіки результатів.
8. Реалізувати автоматичне тестування алгоритмів.

## Реалізовані алгоритми

### 1. Перетворення у відтінки сірого

Алгоритм перетворює кольорове RGB-зображення на зображення у відтінках сірого.

Для обчислення яскравості пікселя використовується формула:

Y = 0.299R + 0.587G + 0.114B

де:

- R — червона компонента;
- G — зелена компонента;
- B — синя компонента;
- Y — обчислена яскравість.

### 2. Корекція яскравості

Алгоритм збільшує або зменшує значення колірних компонентів пікселів.

Користувач може встановлювати величину корекції яскравості.

Значення компонентів обмежуються діапазоном від 0 до 255.

### 3. Гістограмне вирівнювання

Алгоритм змінює розподіл яскравостей пікселів на основі гістограми зображення.

Мета методу — перерозподіл рівнів яскравості для зміни контрастності.

Гістограмне вирівнювання може підсилювати як деталі тексту, так і шум.

### 4. Порогова сегментація

Алгоритм перетворює зображення на чорно-біле за заданим порогом.

Якщо яскравість пікселя більша або дорівнює порогу, він стає білим. Інакше — чорним.

Користувач може змінювати значення порога.

### 5. Морфологічна обробка

Реалізовано дві морфологічні операції:

- ерозія;
- дилатація.

Обробка виконується в локальному вікні заданого розміру.

Підтримуються непарні додатні розміри вікна.

## Метрики оцінювання

Для порівняння початкових та оброблених зображень використовуються три показники.

### MSE

Mean Squared Error — середньоквадратична похибка.

Показує середню квадратичну різницю між відповідними компонентами пікселів двох зображень.

MSE = 0 означає, що масиви пікселів однакові.

### PSNR

Peak Signal-to-Noise Ratio — пікове відношення сигналу до шуму.

Обчислюється на основі MSE.

Вище значення PSNR означає меншу відмінність між порівнюваними зображеннями.

Якщо MSE = 0, PSNR дорівнює нескінченності.

### Global SSIM

Global Structural Similarity Index — глобальна оцінка структурної подібності.

У проєкті використовується спрощена глобальна формула SSIM на основі середньої яскравості, дисперсії та коваріації.

На відміну від стандартного локального SSIM, показник обчислюється для зображення загалом.

Значення 1 означає повну структурну подібність.

Важливо: MSE, PSNR і Global SSIM у цьому проєкті вимірюють подібність обробленого зображення до початкового. Вони не є безпосередньою оцінкою читабельності тексту.

```text
STEM_Image_Processing/
```

Призначення основних файлів:

Папка `dataset/` використовується для локального набору тестових зображень. Самі зображення можуть не входити до репозиторію.

## Встановлення та запуск

### 1. Завантаження репозиторію

```bash
git clone https://github.com/worsiz02-rgb/STEM_Image_Processing.git
```

### 2. Перехід до папки проєкту

```bash
cd STEM_Image_Processing
```

### 3. Встановлення бібліотек

```bash
python3 -m pip install -r requirements.txt
```

Для графічного інтерфейсу також необхідна підтримка Tkinter у встановленій версії Python.

### 4. Запуск графічного інтерфейсу

```bash
python3 main.py
```

## Проведення експериментів

Для автоматичної обробки необхідно створити папку `dataset` у корені проєкту та розмістити в ній тестові зображення.

Підтримувані формати:

- JPG;
- JPEG;
- PNG;
- BMP;
- TIFF.

Запуск:

```bash
python3 experiments.py
```

Програма:

1. Завантажує зображення з `dataset`.
2. Застосовує п'ять алгоритмів.
3. Вимірює час виконання кожного алгоритму.
4. Обчислює MSE, PSNR і Global SSIM.
5. Зберігає оброблені зображення.
6. Формує таблицю `comparison.csv`.

У поточній конфігурації результати експериментів зберігаються у папці `STEM_Image_Processing_results` на Робочому столі користувача.

Перед експериментами найбільша сторона зображення обмежується 700 пікселями для скорочення часу обчислень.

## Автоматичне тестування

Для перевірки правильності алгоритмів використовуються модульні тести на основі unittest.

Тести перевіряють:

- перетворення у відтінки сірого;
- корекцію яскравості;
- обмеження значень пікселів;
- гістограмне вирівнювання;
- порогову сегментацію;
- морфологічну ерозію;
- морфологічну дилатацію;
- обробку некоректних параметрів;
- правильність обчислення метрик.

Запуск тестів:

```bash
python3 -m unittest discover -s tests -p "test_*.py" -v
```

Під час перевірки було успішно виконано 15 тестів.
